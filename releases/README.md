*Si la page affiche « Not Found », la release n'est pas encore publiée. Voir ci-dessous.*

## Publier l'APK (une fois)

Depuis un terminal, avec un token GitHub ayant accès à **Actus** :

```bash
GH_TOKEN=ghp_votre_token ./deploy-to-actus.sh
```

Token : https://github.com/settings/tokens (scope **repo**)

Après ça, le lien ci-dessus fonctionne pour tout le monde, sans adb.
